# English practice

Интерактивные упражнения для уроков английского. Это статичный сайт для GitHub Pages: сборки нет,
все страницы лежат в корне репозитория.

Файлы:

- `index.html`: стартовая страница со ссылками
- `pattern_drill.html`: дриллинг по паттернам глаголов, секундомер
- `advice_choose_word.html`: выбор слова в диалогах про советы
- `robots.txt` и метатеги `noindex`: просьба к поисковикам не индексировать (ссылка при этом открыта всем)
- `.nojekyll`: отключает обработку Jekyll

Как включить: Settings, Pages, Source: Deploy from a branch, ветка `main`, папка `/ (root)`.
